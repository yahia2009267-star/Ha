مشروع فاحص مكوّنات المنتجات — نسخة جديدة

الملفات: index.html و manifest.json و sw.js و icon.svg.

النشر على GitHub Pages:
1) أنشئ مستودعًا جديدًا باسم halal-check (أو أي اسم تختاره).
2) ارفع الملفات الأربعة إلى جذر المستودع، وليس داخل مجلد فرعي.
3) Settings > Pages > Build and deployment: اختر Deploy from a branch، ثم main و /(root)، واضغط Save.
4) انتظر نشر الموقع وافتح الرابط الذي يظهر في صفحة Pages.

الميزات:
- البحث عن المنتج بالباركود عبر Open Food Facts.
- عرض المكوّنات عندما تكون مسجلة في قاعدة البيانات.
- زر بحث ويب يفتح Google باستخدام اسم المنتج والباركود عند نقص المكوّنات.
- يمكن نسخ المكوّنات من مصدر موثوق ولصقها يدويًا ثم تحليلها.
- فحص قائمة المكوّنات المكتوبة أو المصوّرة (إذا كانت المكتبات متاحة والاتصال يعمل).

مهم: صفحة GitHub Pages ثابتة، ولا يمكنها جلب نتائج Google تلقائيًا بصورة موثوقة دون خدمة خلفية أو واجهة بحث API. زر البحث يفتح نتائج البحث فقط؛ لا يستوردها تلقائيًا.

هذا فاحص أولي وليس جهة إصدار شهادة حلال. قد تكون بيانات المنتجات ناقصة، وقد يخطئ التعرّف الضوئي أو تصنيف المكوّنات. عدم ظهور مؤشرات لا يثبت أن المنتج حلال. تحقق من الشركة وشهادة الحلال ومصدر المكوّنات الملتبسة.
